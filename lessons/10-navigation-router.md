# บทที่ 10 — Navigation แบบ Router

> **สถานะ: โครงของบทเรียน** ยังไม่มีบทสอนเต็มและยังไม่มีโค้ดตัวอย่าง ใช้สอนไม่ได้จนกว่าจะเขียนเพิ่ม

- **ที่มาของหัวข้อ:** senior: "Navigation แบบ router"
- **ทำไมต้องเรียน:** โปรเจกต์จริงมีหลายสิบ module ที่ต้องเปิดหน้าจอของกันและกันโดยไม่พึ่งกันโดยตรง
- **ต้องรู้ก่อน:** บทที่ 06, บทที่ 09
- **เรียนจบแล้วไปที่:** workshop Session 4 — Intent, Router และ deep link (ดู [learning.md](../learning.md))

## เรียนจบแล้วทำอะไรได้

- อธิบายได้ว่าทำไม feature module ห้ามเรียก Activity ของ module อื่นตรง ๆ
- เพิ่มเส้นทางใหม่ใน Router ได้ครบทุกจุดที่ต้องแก้

## เนื้อหา

- โปรเจกต์หลาย module และทิศทางการพึ่งพา
- ปัญหาเมื่อ feature สองตัวต้องเปิดหน้าจอของกันและกัน
- interface ของ Router ใน module กลาง, ตัวจริงใน feature, การผูกด้วย DI
- การขอ Router ด้วย `by inject()`
- อีกรูปแบบ: สร้าง Intent จากชื่อ class เป็นข้อความ และข้อแลกเปลี่ยน
- การส่งข้อมูลข้าม module: ชนิดข้อมูลต้องอยู่ที่ใด
- Router กับ deep link ทำงานร่วมกันอย่างไร

## ตัวอย่างที่จะใช้สอน

แยกแอปของบทที่ 08 ออกเป็นสอง module แล้วให้เปิดหากันผ่าน Router
