# บทที่ 08 — Navigation แบบธรรมดา

> **สถานะ: โครงของบทเรียน** ยังไม่มีบทสอนเต็มและยังไม่มีโค้ดตัวอย่าง ใช้สอนไม่ได้จนกว่าจะเขียนเพิ่ม

- **ที่มาของหัวข้อ:** senior: "Navigation แบบธรรมดา"
- **ทำไมต้องเรียน:** แอปจริงมีหลายหน้าจอ และผู้ใช้คาดหวังว่าปุ่ม Back จะทำงานตามที่คิด
- **ต้องรู้ก่อน:** บทที่ 03
- **เรียนจบแล้วไปที่:** บทถัดไป

## เรียนจบแล้วทำอะไรได้

- เปิดและปิดหน้าจอได้ และทำนายได้ว่ากด Back แล้วไปไหน
- รับผลกลับจากหน้าจอที่เปิดไปได้

## เนื้อหา

- `startActivity` และ `finish()`
- back stack และ task
- รูปแบบ `newInstance(context, ...)` ใน `companion object`
- รับผลกลับ: `startActivityForResult` / `onActivityResult` ที่เจอในโค้ดเดิม และ Activity Result API
- การจัดการปุ่ม Back: `OnBackPressedDispatcher`
- flag ที่เจอบ่อย: `CLEAR_TOP`, `NEW_TASK`, `CLEAR_TASK`
- Fragment transaction ระดับรู้จัก: `replace`, `addToBackStack`
- Navigation Component ระดับรู้ว่ามีและต่างจากวิธีข้างบนอย่างไร

## ตัวอย่างที่จะใช้สอน

แอปสามหน้าจอ: รายการ → รายละเอียด → ยืนยัน แล้วส่งผลกลับมาหน้าแรก
