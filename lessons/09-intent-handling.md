# บทที่ 09 — การ handle Intent

> **สถานะ: โครงของบทเรียน** ยังไม่มีบทสอนเต็มและยังไม่มีโค้ดตัวอย่าง ใช้สอนไม่ได้จนกว่าจะเขียนเพิ่ม

- **ทำไมต้องเรียน:** Intent คือช่องทางเดียวที่ข้อมูลเข้ามาสู่หน้าจอ ทั้งจากในแอปและจากนอกแอป
- **ต้องรู้ก่อน:** บทที่ 08
- **เรียนจบแล้วไปที่:** บทถัดไป

## เรียนจบแล้วทำอะไรได้

- ส่งและรับข้อมูลผ่าน Intent ได้อย่างปลอดภัย
- ทำให้แอปเปิดจากลิงก์ภายนอกได้

## เนื้อหา

- explicit กับ implicit Intent
- extra: ชนิดที่ส่งได้, `Parcelable` และ `@Parcelize`, ขนาดที่ไม่ควรเกิน
- อ่าน extra อย่างปลอดภัย: ค่าเริ่มต้นและกรณีไม่มีค่า
- `intent-filter`: action, category, data (scheme, host, path)
- `android:exported` และความหมายด้านความปลอดภัย
- deep link กับ App Link, การทดสอบด้วย `adb shell am start`
- Activity ที่ทำหน้าที่รับลิงก์แล้วส่งต่อ (รูปแบบ `SchemeActivity`)
- `onNewIntent` เมื่อหน้าจอเปิดอยู่แล้ว
- ข้อมูลจากนอกแอปเชื่อถือไม่ได้: ต้องตรวจก่อนใช้
- Intent จาก notification และ `PendingIntent` ระดับรู้จัก
