# บทเรียนรายหัวข้อ

บทเรียนในโฟลเดอร์นี้สอนพื้นฐาน Android ทีละเรื่อง บนตัวอย่างเล็ก ๆ ที่จบในตัวและไม่อิงโครงสร้างหลาย module
เมื่อเรียนครบกลุ่มหนึ่งแล้ว ผู้เรียนนำไปใช้กับโครงสร้างหลาย module ใน [workshop](../workshop/) ตามบทใน [learning.md](../learning.md)

> **สถานะ:** บทที่ 00–02 พร้อมสอน บทที่ 03–12 ยังเป็นโครง ยังใช้สอนไม่ได้

## วิธีดำเนินการสอนบทเรียน (สำหรับ Claude)

กติกาพื้นฐานเหมือนกับ workshop ใน [learning.md](../learning.md): สอนทีละขั้น, ไม่แก้ไฟล์ของผู้เรียนเอง, ไม่เฉลยก่อนผู้เรียนได้ลอง, ใบ้เป็นขั้น, และจด `progress.md` ที่ root ของ repo
สิ่งที่ต่างคือ **ลำดับภายในหนึ่งขั้น** บทเรียนอธิบายก่อนให้ลงมือ:

0. **แนะนำโครงสร้างของโปรเจกต์ก่อนเริ่มบท** ทำครั้งเดียวตอนเปิดบท ก่อนขั้นแรก: บอกว่าโฟลเดอร์และไฟล์แต่ละอย่างในโปรเจกต์ของบทนั้นคืออะไร อันไหนผู้เรียนจะได้แก้ อันไหนไม่ต้องสนใจ แล้วให้ผู้เรียนเปิดดูของจริง ทุกบทมีหัวข้อ "แนะนำโครงสร้าง" สำหรับเรื่องนี้ ห้ามข้าม
1. **อธิบาย** แนวคิดของขั้นนั้นด้วยคำของคุณเอง สั้น และเทียบกับภาษาที่ผู้เรียนถนัดเมื่อช่วยได้
2. **ให้ดูของจริง** ส่งลิงก์ไฟล์ตัวอย่างให้ผู้เรียนเปิดและรัน ถ้าบทสอนบอกให้ทำนายก่อนรัน ให้ถามและรอคำตอบก่อน
3. **ให้แบบฝึก** ทีละขั้น บอกชื่อแบบฝึกและวิธีตรวจ แล้วหยุดรอ
4. **ตรวจ** ด้วยการรัน test ของขั้นนั้นเอง และอ่านโค้ดที่ผู้เรียนเขียน คำตอบที่ต่างจากเฉลยแต่ผ่าน test ถือว่าถูก ให้ชมก่อน แล้วจึงชวนดูแบบที่โค้ดจริงใช้
5. **เชื่อมกับ workshop** บอกหัวข้อ "จะเจอที่ไหน" ทุกครั้ง นี่คือสิ่งที่ทำให้ผู้เรียนรู้ว่าเรียนไปทำอะไร

ถ้าผู้เรียนทำนายผิดหรือทำแบบฝึกผิด นั่นคือจุดที่ต้องสอน อย่าข้ามไปเฉลย ให้ถามว่าคิดอย่างไรก่อน

**ไม่มีการจับเวลา** ผู้เรียนกำหนดจังหวะเอง ไม่ต้องบอกว่าแต่ละขั้นควรใช้เวลาเท่าไร และไม่เร่ง

## โครงของบทเรียนหนึ่งบท

- บทที่พร้อมสอนเป็นโฟลเดอร์ `NN-ชื่อ/` มีบทสอนชื่อ `lesson.md` ส่วนบทที่ยังเป็นโครงเป็นไฟล์ `.md` เดี่ยว เมื่อเขียนบทใดให้ย้ายเข้าโฟลเดอร์
- โค้ดของบทที่ 01–12 อยู่ในโปรเจกต์ Android เดียวกันคือ [playground/](playground/) หนึ่งบทต่อหนึ่ง package (`com.learning.playground.lessonNN`) และ test อยู่ใน package เดียวกันใต้ `app/src/test/` เวอร์ชันของ Gradle, Kotlin และ SDK ตรงกับ workshop
- บทที่ 00 เป็นโปรเจกต์ Kotlin แยกในโฟลเดอร์ของตัวเองเพราะไม่ต้องใช้ Android
- เฉลยอยู่ที่ `solutions/lesson-NN/` ใช้ path เดียวกับโปรเจกต์ของบทนั้น (`lessons/00-kotlin/` หรือ `lessons/playground/`)
- หน้าแรกของ playground คือ `HomeActivity` ซึ่งเป็นสารบัญ เมื่อเขียนบทใหม่ให้เพิ่มปุ่มที่นี่ และประกาศ Activity ของบทใน Manifest
- resource ของแต่ละบทแยกไฟล์และมีชื่อบทกำกับ เช่น `strings_lesson02.xml`, `lesson02_step1_card.xml` ยกเว้นบทที่ 01 ซึ่งใช้ `strings.xml` เพราะสอนไฟล์นั้นโดยตรง ส่วน `colors.xml`, `dimens.xml`, `themes.xml` ใช้ร่วมกัน
- **ไฟล์ที่หลายบทใช้ร่วมกัน** คือ `AndroidManifest.xml`, `app/build.gradle` และ `strings.xml` มีสำเนาฉบับเฉลยอยู่ใน `solutions/lesson-01/` เมื่อแก้สามไฟล์นี้ใน playground ต้องแก้สำเนานั้นให้ตรงกัน ไม่อย่างนั้นการทับเฉลยของบทที่ 01 จะลบของบทอื่น
- test ทุกบทใช้ตัวช่วยอ่าน XML ร่วมกันที่ `app/src/test/java/com/learning/playground/ProjectFiles.kt`
- บทที่สอนหน้าตามีภาพเป้าหมายใน `NN-ชื่อ/targets/` ถ่ายจากเฉลยที่รันบน emulator เมื่อแก้ layout ของเฉลยต้องถ่ายใหม่
