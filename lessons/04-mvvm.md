# บทที่ 04 — MVVM

> **สถานะ: โครงของบทเรียน** ยังไม่มีบทสอนเต็มและยังไม่มีโค้ดตัวอย่าง ใช้สอนไม่ได้จนกว่าจะเขียนเพิ่ม

- **ที่มาของหัวข้อ:** senior: "MVVM"
- **ทำไมต้องเรียน:** เป็นโครงของทุกหน้าจอในโปรเจกต์จริง
- **ต้องรู้ก่อน:** บทที่ 03
- **เรียนจบแล้วไปที่:** บทถัดไป

## เรียนจบแล้วทำอะไรได้

- แยกได้ว่าโค้ดใดควรอยู่ใน Activity และโค้ดใดควรอยู่ใน ViewModel
- เขียน ViewModel ที่ส่งค่าออกทาง LiveData และให้ Activity observe ได้

## เนื้อหา

- ปัญหาของการเขียนทุกอย่างใน Activity
- Model, View, ViewModel แต่ละตัวคืออะไรและรู้จักใครได้บ้าง
- `ViewModel`: อายุยาวกว่า Activity อย่างไร และทำไมรอดจากการหมุนจอ
- `LiveData` / `MutableLiveData` และคู่ `_x` / `x`
- `observe` และทิศทางของข้อมูล: เหตุการณ์ขึ้น, state ลง
- ViewModel ห้ามถือ View, Activity หรือ Context ของหน้าจอ
- ชั้นถัดจาก ViewModel: Repository และ UseCase ระดับแนวคิด (ลงมือในบทที่ 07)
