# coffee-demo-android

หลักสูตรสอน Android ตั้งแต่พื้นฐานจนถึงโปรเจกต์หลาย module โดยมี Claude เป็นผู้สอน เรียนตามจังหวะของคุณเอง ไม่มีการจับเวลา

## เริ่มเรียน

1. เปิดโฟลเดอร์นี้ (โฟลเดอร์นอกสุดของ repo) ด้วย Claude Code ใน terminal หรือ extension ของ VS Code
2. พิมพ์ว่า `เริ่มเรียน`

Claude จะพาเตรียมเครื่องในครั้งแรก แล้วสอนทีละภารกิจ: ให้โจทย์ รอคุณเขียนโค้ด ตรวจงาน แล้วอธิบาย
ครั้งถัดไปพิมพ์ `สอนต่อ` Claude จะทำต่อจากจุดที่ค้างไว้

## ระหว่างเรียน พิมพ์ได้ว่า

| พิมพ์ | ผล |
|---|---|
| `เสร็จแล้ว` | Claude ตรวจงานจากไฟล์ของคุณ |
| `ใบ้หน่อย` | ได้คำใบ้ทีละขั้น |
| `เฉลยเลย` | ดูเฉลยพร้อมคำอธิบาย |

## ไฟล์ในโปรเจกต์

| ไฟล์ / โฟลเดอร์ | คืออะไร |
|---|---|
| `workshop/` | โปรเจกต์ Android ที่คุณจะเขียนโค้ดลงไป **เปิดโฟลเดอร์นี้ด้วย Android Studio** |
| `learning.md` | บทสอนของ workshop ที่ Claude ใช้ มีเฉลยอยู่ข้างใน ไม่ควรเปิดอ่านล่วงหน้า |
| `lessons/` | บทเรียนพื้นฐานรายหัวข้อ เรียนก่อน workshop (พร้อมแล้วบทที่ 00 Kotlin, 01 Android Studio และ 02 Layout ที่เหลือกำลังจัดทำ) |
| `agent.md` | โครงสร้างและ convention ของโปรเจกต์ |
| `solutions/` | เฉลยราย session ใช้ผ่าน `workshop/scripts/catch-up.sh` ตอนตามไม่ทัน |
| `review/` | ฉบับเฉลยครบสำหรับส่งให้คนอื่น review |
| `CLAUDE.md` | บอก Claude ว่าต้องสอนตามไฟล์ไหน |
